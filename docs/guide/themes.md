# 安装与使用主题

主题替换首页和登录页，管理后台继续使用默认界面。网站名称、简介、Logo、favicon 和站点语言在 **站点设置** 中配置。

## 安装与配置

准备主题 ZIP，例如 [Horizon](https://github.com/llleixx/picloom-extensions/blob/main/themes/horizon/README.md)。以 Owner 登录，在 **管理后台 → 主题** 上传 ZIP，确认包信息与信任提示后安装。

1. 选择“配置”，填写主题字段并保存草稿。
2. 点击“预览首页／登录页”，查看已保存草稿。
3. 点击“应用到网站”，将当前配置和主题版本一起启用。仅保存草稿不会改变网站。

每个版本独立配置，新版本从默认值开始，不复制旧版配置。主题未提供的页面使用默认页面。

## 语言与字段编辑

主题面板中的语言用于草稿预览，应用时也会更新站点默认语言。可选语言需同时由站点启用、主题支持。

多语言字段通过“编辑翻译”填写，完成后保存草稿或应用。缺失翻译不会借用其他语言，必需翻译需要补齐。列表的增删和排序对全部语言共用。

图片字段填写 URL；文本清空后保留空字符串，可选数字清空表示未设置。

## 恢复默认页面

打开 `/?theme=default` 或 `/login?theme=default` 强制使用默认页面，登录后台后恢复默认主题。在对应版本的「…」菜单中选择“卸载”，会删除该版本草稿。启用中的版本不能卸载，恢复默认后即可卸载。

主题加载失败时当前页面会回退到默认界面，不改变全站启用配置。主题数据的备份见[主题数据](../operations/data.md#主题数据)。
