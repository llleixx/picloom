# 安装与使用主题

主题可替换首页和登录页，管理后台使用默认界面。主题代码可读取页面数据，登录主题也能读取输入的凭据；仅站点所有者可安装，请选择可信来源。

## 安装与配置

在 **管理后台 → 主题** 上传 ZIP，检查名称与版本，确认信任后安装。安装不会自动启用。

选择“配置”，编辑后保存草稿；“预览首页／登录页”使用已保存草稿并在新窗口打开。“应用到网站”保存当前编辑内容并将版本与配置一起发布。保存草稿本身不改变线上内容。预览中的上传、登录是真实操作，不要把预览当作测试数据隔离区。

一个主题版本作用于整站；缺少首页或登录页时，该页使用默认页面。每个版本独立安装和配置，新版本从自己的 Schema 默认配置开始，不提供跨版本配置复制或迁移。启用版本不能卸载；恢复默认后可以卸载，卸载也会删除该版本草稿。

网站名称、简介、Logo、favicon 和站点语言仍在站点设置里，主题通过 SDK 读取。主题的宣传文案不会修改网站名称或浏览器标题。图片只需普通 URL 配置，不提供专用上传流程。

## 语言与字段编辑

站点默认语言由站点设置和主题面板共同管理。面板中的语言选择用于草稿预览，应用时与主题配置一起发布；必须选择站点已启用且主题支持的语言。若站点语言已被其他操作修改，请刷新后重新确认。

多语言字段显示当前默认语言，通过“编辑翻译”填写其他语言。确认弹窗只更新表单，仍需保存草稿或应用；取消则丢弃弹窗修改。数组增删和排序对全部语言共用。

可选数字清空表示未设置，文本清空保留空字符串；多语言文本移除只影响当前语言，移除对象会删除整个分组。缺失翻译不会自动使用其他语言，预览和应用前须补齐所有必需翻译。

## 恢复默认页面

- 访问 `/?theme=default` 或 `/login?theme=default`，可在导入主题前强制使用默认页面。
- 后台未登录时使用默认登录页，登录失败后仍保留默认模式。
- 加载失败或挂载异常会自动回退当前页面，不改变全站启用配置；主题死循环时自动回退不一定生效，可重新打开默认入口。
- 登录后台后恢复默认主题，即可卸载原启用版本。

主题清单不兼容时会保留包和草稿，运行时使用默认页面。备份位置见[主题数据](../operations/data.md#主题数据)。开发主题请看[主题快速开始](../development/theme-tooling.md)。
