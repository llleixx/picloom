# 常见场景

以下示例从 [快速开始](./quick-start.md) 的默认配置出发，由管理员配置。存储源、存储组和上传配置的默认名称均为 `Default`。

| 想实现什么 | 场景 |
| --- | --- |
| 同一张图片保存到两个存储源 | [同时保存到本地和 S3](#同时保存到本地和-s3) |
| 根据链接生成不同尺寸的图片 | [用同一张原图生成不同尺寸](#用同一张原图生成不同尺寸) |
| 保存的图片统一带水印 | [为博客图片添加水印](#为博客图片添加水印) |
| 上传后自动检查违规内容 | [上传后自动审核图片](#上传后自动审核图片) |

## 同时保存到本地和 S3

保留本地存储，每次上传再向 S3 保存一份副本。

1. 按 [S3 配置说明](./storage.md#添加-s3-兼容存储) 创建存储源，命名为 `S3`。
2. 打开 **配置 → 存储组**，编辑 `Default`，按下表配置并保存。

| 配置项 | 设置 |
| --- | --- |
| 成员及顺序 | 本地源 `Default` 在前，`S3` 在后 |
| 主存储策略 | 按优先级 |
| 冗余策略 | 按优先级 |
| 冗余副本数 | `1` |

通过 `Default` 上传配置上传一张图片，在图片详情的「副本」中确认本地与 S3 均为就绪。冗余副本在后台写入，上传返回后可能需要稍等。

此设置只影响后续上传，不会为已有图片补副本。副本冗余不能替代 [备份](../operations/data.md)：删除图片会清理所有存储副本。

## 用同一张原图生成不同尺寸

通过链接参数缩放、裁剪或转换格式，不改动存储中的原图。

1. 打开 **配置 → 流水线**，编辑全局访问流水线，添加 **Sharp 图片处理** 步骤。
2. 固定配置保留默认值，在请求参数中启用 `w`、`h`、`fit`、`q`、`format`，保存。
3. 选一张足够大的静态 JPEG 图片，将下表中的域名和路径替换为它的公开链接，分别打开验证。

| 链接示例 | 效果 |
| --- | --- |
| `https://img.example.com/i/photo.jpg?w=320` | 等比缩放，宽度不超过 320 像素 |
| `https://img.example.com/i/photo.jpg?w=640&h=360&fit=cover` | 裁剪为 640 × 360 像素 |
| `https://img.example.com/i/photo.jpg?w=640&format=webp&q=80` | 缩放后输出质量为 80 的 WebP |

默认不放大小图。不带参数时，该步骤不改变图片；若流水线还有其他步骤，仍会按其配置执行。更多参数见 [图片参数](../reference/image-params.md)。

## 为博客图片添加水印

建立独立的博客上传入口，让通过该入口保存的图片带有文字水印。

1. 在 **配置 → 流水线** 创建上传阶段的流水线，命名为“博客水印”。
2. 添加 **水印** 步骤，按下表配置，其他字段保留默认值。

| 字段 | 示例值 |
| --- | --- |
| 水印类型 | 文字 |
| 文字 | `example.com` |
| 尺寸模式 | 相对尺寸 |
| 字号（短边百分比） | `3` |
| 边距（短边百分比） | `2` |
| 位置 | 右下 |
| 不透明度（%） | `70` |

3. 在 **配置 → 上传配置** 创建“博客图片”：公开前缀填 `/blog/`，路径插件选“随机路径”，存储组选 `Default`，上传流水线选“博客水印”。
4. 在上传页选择“博客图片”，上传一张 JPEG 图片，打开返回链接，确认右下角出现水印。

水印会写入保存的图片，之后取消流水线也不会移除已有水印。使用中文文字时，服务器需有相应字体，也可填写服务器或容器内的字体文件路径。

若希望保留无水印原图，可将水印步骤放在全局访问流水线中，只处理访问结果。开放 `watermark` 请求参数后，访问者可用 `watermark=false` 跳过水印。

## 上传后自动审核图片

使用腾讯云内容审核，在图片保存后自动屏蔽或删除违规图片。

1. 在 **配置 → 流水线** 创建保存后阶段的流水线，命名为“图片审核”，添加 **腾讯云内容审核**。
2. 填写以下必要配置，其他字段可保留默认值。

| 配置项 | 填写说明 |
| --- | --- |
| 密钥 ID、密钥 | 腾讯云审核服务的凭证 |
| 地域、BizType | 按腾讯云审核服务和策略配置填写 |
| 送审方式 | 选“文件内容”，直接提交图片内容 |
| 内容大小上限 | 默认 `5 MiB`；超出上限会审核失败，不代表审核通过 |
| 违规处置 | 选择屏蔽或删除；需要人工复核的结果会屏蔽图片 |

3. 编辑需要审核的上传配置，将保存后流水线设为“图片审核”。
4. 通过该配置上传测试图片，在图片详情的后台操作和处理结果中检查审核是否完成、图片是否被屏蔽。

若改用 URL 送审，先配置 [图片域名](../operations/proxy.md)，并确保腾讯云可以访问图片；防盗链和存储跳转可能影响读取。

::: warning 审核时机
审核在图片发布后执行，图片可能在审核完成前已经可访问，不适合要求“审核通过后才首次公开”的用途。
:::
