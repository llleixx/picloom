# 常见场景

以下示例接着 [快速开始](./quick-start.md) 的“本地图片 → 本地组 → 默认上传”配置操作。配置由 Owner 或 Admin 完成。

## 多保存一份副本

1. 按 [S3 配置说明](./storage.md#添加-s3-兼容存储) 创建第二个存储源并确认就绪。
2. 编辑“本地组”，加入 S3 源，将本地源排在前面。
3. 主存储与冗余策略均选择“按优先级”，冗余副本数填 `1`，保存。
4. 通过“默认上传”上传一张新图片，到该图片的操作详情查看副本。

完成后应有本地与 S3 两份就绪副本。后台写入需要时间；若一直未完成，查看任务错误并检查 S3 读写权限。这不会为以前上传的图片补副本。

## 访问时生成缩略图

1. 打开 **配置 → 流水线**，编辑全局访问流水线。
2. 添加 **Sharp 图片处理** 步骤。
3. 在步骤的请求参数中启用 `w`、`h`、`fit`、`q`、`format`，保存。
4. 选择一张静态 JPEG 图片，将它的公开链接分别加上以下参数后打开。

| 参数 | 预期结果 |
| --- | --- |
| `?w=320` | 等比缩小，宽度不超过 320 像素 |
| `?w=640&h=360&fit=cover` | 对足够大的原图按 16:9 裁剪，输出 640 × 360 像素 |
| `?w=640&format=webp&q=80` | 缩放后输出质量为 80 的 WebP |

原链接仍返回未经过该缩放步骤处理的内容，存储中的原图不变。默认不放大小图；其他适配方式见 [图片参数](../reference/image-params.md)。

参数没有效果时，先检查步骤是否保存、相应请求参数是否勾选，再检查图片格式是否受支持。不支持的输入按步骤配置跳过或中止。

## 上传时添加水印

1. 在 **配置 → 流水线** 创建上传阶段的流水线，命名为“博客水印”。
2. 添加 **水印** 步骤，使用下面的配置；其他字段保留默认值。
3. 编辑“默认上传”，将上传流水线设为“博客水印”，保存。
4. 上传一张新的 JPEG 图片，打开返回链接，确认右下角出现水印。

| 字段 | 示例值 |
| --- | --- |
| 水印类型 | 文字 |
| 文字 | `example.com` |
| 尺寸模式 | 相对尺寸 |
| 字号（短边百分比） | `3` |
| 边距（短边百分比） | `2` |
| 位置 | 右下 |
| 不透明度（%） | `70` |

保存的图片已包含水印，之后取消流水线也不会移除已有水印。若使用中文文字，需要服务器上有相应字体；可填写容器或服务器可读的字体文件路径。图片水印的路径同样是服务器路径，不是浏览器电脑上的路径。

如果希望保留无水印原图，将水印步骤放在访问阶段。该步骤默认执行；若开放 `watermark` 请求参数，访问者可用 `watermark=false` 跳过，因此不能用它保证原图始终不可获取。

## 接入审核与通知

先准备腾讯云审核凭证和策略 ID，以及可接收 HTTP POST 的 Webhook 地址。在 [域名设置](../operations/proxy.md) 中配置站点或图片域名，供后台任务生成完整图片 URL。

1. 创建保存后阶段的流水线，添加 **腾讯云内容审核**。
2. 填写密钥 ID、密钥、地域和 BizType（策略标识）。送审方式选择“文件内容”时，设置内容大小上限；默认 `5 MiB`，超出后任务失败且不重试。
3. 选择违规时屏蔽或删除。需要人工复核的审核结果会屏蔽图片。
4. 在审核步骤后添加 **Webhook**，填写目标链接；接收端需要认证时，再填写 Bearer 令牌。
5. 将流水线绑定到上传配置，上传测试图片，在操作详情查看执行结果，并在接收端确认通知。

审核通过才会继续后面的通知；屏蔽或删除会停止后续步骤。使用 URL 审核模式时，图片必须能被腾讯云访问，防盗链或存储跳转可能影响读取。

::: warning 审核时机
保存后审核在上传返回链接后执行，图片可能在审核完成前已经可访问。它不适合要求“审核通过后才首次公开”的用途。
:::

Webhook 发送 `file.saved` 事件，包含文件 ID、URL 和图片元数据。后台重试可能重复发送，接收端应按 `Idempotency-Key` 请求头去重；具体载荷见 [内置插件](../reference/plugins.md#webhook-通知)。
