# 安装与使用插件

内置插件无需安装。OpenList、NodeImage、Telegram 存储和腾讯云审核等外部插件需先安装 ZIP，才能在配置中选择。可用插件见[官方插件](../reference/plugins.md)。

## 安装并配置

准备作者提供的插件 ZIP；官方扩展也可按[扩展仓库说明](https://github.com/llleixx/picloom-extensions#development)从源码构建。

1. 以 Owner 登录，在 **管理后台 → 插件** 上传 ZIP，确认包信息与信任提示后安装。
2. 加载成功后，按插件类型创建配置：

| 类型 | 配置入口 | 如何使用 |
| --- | --- | --- |
| 存储 | 配置 → 存储源 | 填写连接信息，加入存储组，再由上传配置选择该组 |
| 路径 | 配置 → 上传配置 | 选择路径插件并填写路径规则 |
| 处理 | 配置 → 流水线 | 在支持的阶段添加步骤；上传和保存后流水线还需由上传配置选择 |

安装不会自动创建上述配置。必需字段和使用限制见各插件的[参考页](../reference/plugins.md)。插件在服务进程中运行，可访问服务器资源，因此仅 Owner 能安装。

## 更新与卸载

安装新版后，编辑使用该插件的存储源、上传配置或流水线步骤，选择新版本，检查迁移预览并保存。已有配置不会自动切换；同 ID、同版本不能覆盖不同内容。

旧版本仍被配置或文件副本引用时不能卸载，按页面提示处理引用后即可卸载。内置插件随应用更新。
