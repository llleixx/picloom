# 用户、游客与令牌

| 身份   | 主要权限                                                   |
| ------ | ---------------------------------------------------------- |
| Owner  | 全部管理能力，包括安装插件包、备份恢复和管理管理员         |
| Admin  | 站点配置、文件管理及成员管理；不能安装插件包或执行备份恢复 |
| Member | 在允许范围内上传，管理自己的图片与上传令牌                 |
| 游客   | 仅在开放游客的上传配置及游客额度内上传                     |

## 上传令牌

上传令牌供脚本或第三方工具使用，不必向这些工具提供账户密码。

1. 打开 **上传令牌**，填写便于识别的名称，例如“博客发布脚本”。
2. 选择有效期；也可以设置具体过期时间或不过期。
3. 选择允许使用的上传配置。只需要博客上传时，选择对应配置即可。
4. 创建后复制并保存完整令牌。离开页面后无法重新查看完整值，丢失时需重新创建。

请求使用 `Authorization: Bearer <令牌>`。调用示例见 [HTTP API](../reference/http-api.md#上传一张图片)，ShareX 和 PicGo 配置见[外部集成](./integrations.md)。令牌可查询权限范围内的上传配置并上传，不能用于管理文件、修改配置或执行备份。

停用脚本或怀疑泄露时，在列表中撤销该令牌；之后的请求将无法继续使用它，已有图片不受影响。

## 开放游客上传

1. 编辑要开放的上传配置，开启“允许游客上传”。
2. 在设置页填写游客单文件大小与每日上传额度。每日额度 `0` 表示禁止上传，留空表示不额外限制每日次数。
3. 使用未登录的浏览器窗口访问上传页，确认能够选择该配置并上传测试图片。

游客每日额度按识别到的客户端 IP 计算。部署在反向代理后时，需按 [反向代理说明](../operations/proxy.md) 设置真实 IP；否则多个访客可能共用一个额度。游客上传仍受全局和上传配置的限制。

## 公开图片访问

持有公开链接即可访问可用图片；成员权限主要保护管理接口。防盗链依据请求来源判断，不等同于私有图片授权。

账户密码可在账户页修改。忘记 Owner 密码时使用 [恢复命令](../operations/troubleshooting.md#忘记-owner-密码)。
