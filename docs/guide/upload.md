# 上传与分享

上传前需要有可用的上传配置。首次部署尚未创建配置时，请先完成 [快速开始](./quick-start.md)。

## 上传图片

1. 打开上传页，选择要使用的上传配置。页面会显示该配置允许的格式和单张大小。
2. 点击选择文件、拖入图片，或直接粘贴剪贴板中的图片。可以一次选择多张。
3. 等待各项显示上传成功，再复制链接。批量上传时，每张图片分别显示结果。

网页会根据服务配置自动选择普通上传或分片上传，无需手工切分文件。排队中或传输中的项目可以取消；进入处理阶段后需等待结果。分片上传失败后，如果页面提供继续入口，可以继续传输；这不保证刷新或关闭页面后仍能续传。

## 从图片链接上传

在上传区域粘贴公开的 HTTP 或 HTTPS 图片链接；多个链接用空白分隔。Picloom 会从服务器下载图片，并按所选上传配置保存。

链接应直接返回图片，不能是包含图片的网页。需要登录、依赖浏览器 Cookie、限制来源的地址可能下载失败；本地或内网地址也会受到服务的地址校验限制。

从链接上传会在 Picloom 的存储中保存一份图片，与 [导入已有文件](./files.md#导入已有文件) 只登记现有对象不同。

## 复制与嵌入

上传结果支持 URL、Markdown、HTML 和 BBCode，也可以一次复制所有成功项的链接。以后仍可在图片管理页找到已上传的图片。

例如，将返回链接嵌入 Markdown：

```markdown
![图片说明](https://img.example.com/i/9b7c6d5e4f304162a8b9c0d1e2f34567.jpg)
```

上面只是格式示例，请替换为实际上传返回的 URL。公开链接无需登录即可访问；上传令牌不应放进分享链接。

## 生成缩略图链接

先由管理员配置访问流水线并启用图片参数。随后可在图片详情中生成处理后链接，或在原链接后追加参数：

```text
https://img.example.com/i/9b7c6d5e4f304162a8b9c0d1e2f34567.jpg?w=320&format=webp
```

处理结果不覆盖存储中的原图。完整配置步骤见 [访问时生成缩略图](./recipes.md#访问时生成缩略图)。

## 上传失败

优先查看失败项的提示。大小或格式不符时，更换图片或由管理员调整对应限制；没有可用上传配置时，检查配置权限和存储状态。其他问题见 [故障排查](../operations/troubleshooting.md)。
