# 容量与并发

## 运行统计

在 **系统 → 统计概览** 查看图片增长、格式与存储分布，点击对应数据进入图片列表。原图按就绪图片统计。存储分布按副本记账，包含待写入及失败副本，和远端实际用量可能不同。本地目录占用、数据盘可用空间和失败任务见 **系统 → 运行维护**。

## 文件限制

在 **设置 → 上传** 调整单文件大小，在 **设置 → 处理与任务** 调整图片边长和像素数上限。评估内存时应考虑解码后的像素量和同时处理的图片数。

## 并发与队列

| 设置 | 作用 | 默认值 | 设置入口 |
| --- | --- | --- | --- |
| 并发上传文件数 | 限制同时接收或完成的上传工作，也用于浏览器安排文件上传 | 4 | 上传 |
| 单文件并发分片数 | 限制一个上传会话同时接收的分片 | 2 | 上传 |
| 图片处理并发数 | 限制同时执行的受控图片处理工作 | 2 | 处理与任务 → 高级设置 |
| 图片处理队列长度 | 处理名额用尽后允许等待的工作数量 | 16 | 处理与任务 → 高级设置 |
| 存储写入并发数 | 限制同时执行的上传写入、剩余副本写入和写入重试 | 4 | 处理与任务 → 高级设置 |
| 上传后处理并发数 | 限制同时执行的完整保存后流水线 | 2 | 处理与任务 → 高级设置 |
| 删除并发数 | 限制同时执行的远端副本删除 | 2 | 处理与任务 → 高级设置 |

图片处理队列满时，新请求返回忙碌（`BUSY`）。增加队列只增加等待名额，不会让处理更快。

写入、上传后处理和删除独立使用名额，不互相借用，默认最多同时运行 8 个任务。提高并发后补充派发；降低并发不打断正在运行的任务。写入优先推进尚无成功副本的上传，持续上传时剩余副本可能等待更久，并继续占用临时内容。

环境变量与 API 字段见 [设置参考](../reference/settings.md#并发与图片处理)。

## 服务端缓存与客户端缓存

在 **设置 → 缓存** 调整服务端缓存容量、派生缓存保留时间和图片响应缓存时间。服务器还需为原图、数据库和备份预留空间。

| 类型 | 用途 | 运行行为 |
| --- | --- | --- |
| 临时缓存 | 上传、分片合并及后台任务使用的临时文件 | 空间不足时拒绝新上传或写入，已有任务继续使用其临时文件 |
| 派生缓存 | 缩略图等访问处理结果 | 淘汰或过期后，后续访问会按需重新处理 |
| 浏览器/CDN 缓存 | 客户端或 CDN 保存的图片响应 | 有效期内可能继续展示已删除或屏蔽的图片，清理服务端缓存对此无效 |

缓存默认值与参数见 [设置参考](../reference/settings.md#缓存)。临时缓存不足时见 [故障排查](./troubleshooting.md#临时缓存空间占用较高)。
