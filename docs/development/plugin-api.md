# 处理插件

按处理时机选择要实现的阶段。

| 阶段                                    | 示例需求                 | 处理结果                 |
| --------------------------------------- | ------------------------ | -------------------------------- |
| [上传处理](./processors/upload.md)      | 保存前缩小图片、添加水印 | 最终存储的图片内容与归类         |
| [访问处理](./processors/access.md)      | 用链接参数请求缩略图     | 本次访问结果，原图不变           |
| [保存后处理](./processors/post-save.md) | 替换或审核已保存图片、发送通知 | 图片内容、归类、公开可用状态或外部操作 |

各阶段通过 `process` 接收当前内容并将接受的结果交给后续步骤；保存后阶段还可累计屏蔽或删除决定。

## 定义与阶段

| 定义字段           | 类型                                            | 必需 | 含义                           |
| ------------------ | ----------------------------------------------- | ---- | ------------------------------ |
| `kind`             | `"processor"`                                   | 是   | 插件类型                       |
| `stages`           | `StageDefinitions`                              | 是   | 至少包含一个阶段描述           |
| `stages.upload`    | `Descriptor<UploadPlugin>`，可附 `paramsSchema` | 否   | 上传处理实现                   |
| `stages.access`    | `Descriptor<AccessPlugin>`，可附 `paramsSchema` | 否   | 访问处理实现                   |
| `stages.post_save` | `Descriptor<PostSavePlugin>`                    | 否   | 保存后处理实现，不支持请求参数 |

其他身份字段见 [插件基础](./plugin-start.md#入口定义)，各阶段描述的必需和可选字段见 [配置描述字段](./plugin-start.md#配置描述字段)。
