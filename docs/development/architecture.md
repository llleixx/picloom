# 架构与数据流

## 模块职责

| 目录或模块        | 职责                                       |
| ----------------- | ------------------------------------------ |
| `src/http`        | 请求路由、认证入口、请求与响应转换         |
| `src/core`        | 文件、上传、配置、用户和后台任务等业务规则 |
| `src/persistence` | 持久化接口与 SQLite / PostgreSQL 实现      |
| `src/plugins`     | 插件包、配置验证、实例创建与释放           |
| `src/builtins`    | 使用公共协议实现的内置插件                 |
| `plugin-sdk`      | 插件协议和文件操作辅助能力                 |
| `shared`          | 前后端共用类型、校验和显示协议             |
| `web`             | Vue 管理与上传界面                         |
| `src/runtime.ts`  | HTTP 运行期、维护循环、备份与停机协调      |

## 上传链路

```text
HTTP / 分片会话
  → 身份、额度与配置校验
  → 临时空间与上传处理
  → 路径生成、主副本写入
  → 数据库发布文件
  → 返回链接
  → 后台冗余写入 / 保存后处理
```

发布前失败不能留下可用的公开记录。远端操作结果不确定时保留状态，交给恢复流程确认。

## 访问链路

```text
公开路径 → 可访问状态检查 → 参数与访问流水线
  ├─ 无需变换：读取副本，返回流或跳转
  └─ 需要变换：缓存命中，或读取原图并执行处理
```

派生处理共用并发限制和临时空间预算。同一可缓存结果可以共享处理工作，一个请求取消不应中断其他消费者。

## 后台与资源边界

任务执行器按空闲名额领取任务，完成后自动补充，定时轮询发现新任务和到期重试。恢复清理单独运行；短锁保护同一文件的领取与清理登记，不覆盖插件执行。

备份先暂停领取，再等待在途工作；停机停止新工作并发出取消。数据库状态复查与在途资源保护分别承担业务一致性和资源生命周期职责。

详细状态见 [状态与后台任务](./states.md)。
