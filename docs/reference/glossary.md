# 术语

| 名称 | 含义 |
| --- | --- |
| 上传配置 / Profile | 用户选择的上传入口，组合路径、存储组和处理流水线 |
| 存储源 / Storage source | 一份存储插件实例配置，代表一个具体存储位置 |
| 存储组 / Storage group | 组织存储源，选择存储目标与副本数 |
| 流水线 / Pipeline | 某个处理阶段按顺序执行的一组步骤 |
| 插件实例 / Plugin instance | 插件按一份配置创建的运行对象 |
| 文件 / File | 可管理、具有公开路径的图片记录 |
| 副本 / Replica | 文件在某个存储源中的内容及状态 |
| 逻辑路径 / logicalKey | 文件在公开前缀内的相对路径 |
| 存储路径 / storageKey | 传给存储插件的对象键，可与逻辑路径不同 |
| 定位信息 / locator | 存储插件返回并持久化的额外信息，如远端文件 ID |
| 操作标识 / operationId | 一次可重试操作的稳定标识，用于幂等与恢复 |
| 原图 / Original image | 上传处理后实际保存的图片，不一定与上传输入字节相同 |
| 派生缓存 / Derived cache | 可从原图重新生成的访问结果 |
| 临时缓存 / Temporary cache | 上传接收、处理中间结果及后台源文件使用的空间 |

从使用流程理解这些概念，见 [理解 Picloom](../guide/concepts.md)。
