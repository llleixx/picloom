# 术语

| 名称               | 含义                                           |
| ------------------ | ---------------------------------------------- |
| 上传配置 / Profile | 用户选择的上传入口，组合路径、存储组和处理流程 |
| 存储源 / Source    | 一份存储插件实例配置                           |
| 存储组 / Group     | 组织存储源并选择主副本与冗余副本               |
| 流水线 / Pipeline  | 某阶段按顺序执行的处理步骤                     |
| 实例 / Instance    | 插件按一份配置创建的运行对象                   |
| 文件 / File        | 数据库中可管理、具有公开路径的图片记录         |
| 副本 / Replica     | 文件在某个存储源中的内容及状态                 |
| `logicalKey`       | 文件公开路径中的逻辑键                         |
| `storageKey`       | 传给存储插件的对象键                           |
| `locator`          | 插件返回并持久化的额外定位信息                 |
| `operationId`      | 一次可重试业务操作的标识，用于幂等与恢复       |
| 原图               | 上传处理后实际保存的图片内容                   |
| 派生缓存           | 可从原图重新生成的访问结果                     |
| 临时缓存           | 接收上传、处理中间结果及后台源文件使用的空间   |
| `unknown`          | 无法确认远端操作结果，不等同于未发生           |

从操作视角理解这些概念，见 [理解 Picloom](../guide/concepts.md)。
