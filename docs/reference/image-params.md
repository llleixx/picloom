# 图片参数

参数由访问流水线中的插件提供，并由步骤显式启用。未启用的参数不会传给插件；已启用参数的值不合法时会报错。

## 内置图片变换

| 参数     | 可选值                               | 含义                     |
| -------- | ------------------------------------ | ------------------------ |
| `w`      | 正整数                               | 目标宽度                 |
| `h`      | 正整数                               | 目标高度                 |
| `fit`    | `inside`、`cover`、`contain`、`fill` | 尺寸适配方式，需要宽或高 |
| `q`      | 1–100                                | 编码质量                 |
| `format` | `jpeg`、`png`、`webp`                | 输出格式                 |

含透明通道的图片转换为 JPEG 会被判为不适用，按步骤策略跳过或中止。默认不放大原图；可在插件配置中允许放大。处理仍受最大尺寸与像素限制。内置变换面向静态 JPEG、PNG、WebP；其他格式按步骤的不适用策略处理。

```text
<上传返回的URL>?w=320&format=webp
<上传返回的URL>?w=640&h=360&fit=cover&q=80&format=jpeg
```

### 如何选择 fit

以下以 1600 × 900 原图和 `w=640&h=480` 为例，默认不允许放大：

| 值 | 行为 | 示例结果 |
| --- | --- | --- |
| `inside`（默认） | 保持比例，限制在宽高范围内 | 640 × 360，不裁剪 |
| `cover` | 保持比例，裁去超出部分以填满指定尺寸 | 640 × 480，左右部分被裁去 |
| `contain` | 保持比例，以留边方式补齐指定尺寸 | 640 × 480，上下留边 |
| `fill` | 直接拉伸到指定尺寸 | 640 × 480，比例改变 |

只需要等比缩小，一般传 `w` 或 `h` 即可。`q` 控制编码质量，不是输出文件大小百分比；省略时，JPEG 和 WebP 使用质量 80，PNG 不主动启用调色板压缩。给 PNG 指定 `q` 时会启用调色板编码，结果可能减少颜色数量。

## 水印

访问阶段水印步骤默认执行水印处理；若显式开放布尔参数 `watermark`，访问者可用 `?watermark=false` 跳过该步骤。水印内容和位置在插件配置中设置。

不要依靠可选的 URL 水印参数保护无水印原图。需要保存内容始终含水印时，使用上传阶段水印。

更多组合见 [常见场景](../guide/recipes.md)。
